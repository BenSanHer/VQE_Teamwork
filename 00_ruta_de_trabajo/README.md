# 00_ruta_de_trabajo

## Propósito
Este espacio define la **dirección del trabajo semanal**.

Aquí no hay código ni notebooks.  
Aquí se establece qué se va a hacer, con qué alcance y cuál es el objetivo.

---

## Estructura

Cada semana se organiza en una carpeta:

week_XX_nombre/
├── objetivos.md
├── alcance.md
└── entregable.md



---

## ¿Qué contiene cada semana?

### objectivos.md
Define qué queremos lograr durante la semana.

### alcance.md
Define los límites del trabajo:
- qué se incluye
- qué NO se incluye

### entregable.md
Define el resultado esperado al final de la semana.


## Cómo se usa

1. Antes de empezar la semana:
   - Se define la carpeta de la semana
   - Se establecen objetivos, alcance y entregable

2. Durante la semana:
   - Este espacio sirve como referencia constante

3. Al final:
   - Se valida si el entregable se cumplió


## Regla importante

Si algo no está definido aquí, no es prioridad.


## Objetivo

Mantener claridad en el trabajo y evitar desviaciones innecesarias.
