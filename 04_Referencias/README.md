# 04_referencias

## Propósito
Este espacio contiene todas las **fuentes externas** que usamos para aprender.

Aquí no se desarrolla contenido propio.  
Aquí se centralizan los recursos que nos ayudan a entender.

---

## ¿Qué tipo de contenido va aquí?

- Papers
- Videos
- Tutoriales
- Artículos
- Documentación (ej: Qiskit)

---

## Estructura sugerida

- `papers/` → artículos académicos
- `videos/` → clases o explicaciones
- `links.md` → recopilación de enlaces útiles

---

## Cómo usar este espacio

Si encuentras un recurso útil:

1. Agrégalo aquí
2. (Opcional) añade una breve descripción de por qué es útil

Ejemplo:

```markdown
- [Título del recurso](link)
  Breve descripción de qué explica y por qué es relevante
