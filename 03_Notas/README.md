# 03_notas

## Propósito
Este espacio contiene la **síntesis colectiva del aprendizaje** del equipo.

Aquí no va código experimental ni notebooks desordenados.  
Aquí va lo que ya fue entendido y puede explicarse con claridad.



## ¿Qué tipo de contenido va aquí?

- Resúmenes de conceptos clave (ej: qué es VQE, qué es un ansatz)
- Explicaciones en lenguaje claro
- Glosario de términos importantes
- Errores comunes que encontramos
- Intuiciones que ayuden a entender mejor el algoritmo



## Estructura sugerida

- `vqe_summary.md` → explicación general del algoritmo
- `glossary.md` → términos importantes
- `common_mistakes.md` → errores típicos



## Regla importante

Si algo está aquí, significa que:

> Ya lo entendemos lo suficiente como para explicarlo sin depender del código.



## Objetivo

Construir una base de conocimiento clara que nos permita:
- entender lo que estamos haciendo
- explicarlo a otros
- reutilizarlo en futuras semanas
