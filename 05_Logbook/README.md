# logbook

## Propósito
Este espacio contiene el **registro del proceso de trabajo del equipo** a lo largo de la semana.

Cada integrante documenta su aprendizaje de forma individual, mientras que el equipo mantiene un resumen global del progreso.

---

## Estructura

```
logbook/
├── benjamin/
│   ├── 27-04-2026.md
│   ├── 28-04-2026.md
│   └── ...
├── ivan/
│   ├── 27-04-2026.md
│   └── ...
├── said/
│   ├── 27-04-2026.md
│   └── ...
└── summary.md
```

---

## Logbook individual

Cada integrante mantiene su propio registro diario.

### Formato sugerido

```
# Fecha: DD/MM/AAAA

## Trabajo realizado
## Conceptos entendidos
## Dudas
## Problemas
## Avances
```

---

## Summary (resumen del equipo)

Archivo: `summary.md`

Contiene un resumen global del progreso del equipo.

### Contenido sugerido

- Qué se logró como equipo
- Bloqueos principales
- Decisiones tomadas
- Siguientes pasos

---

## Reglas importantes

- Cada persona escribe solo en su carpeta
- Se debe usar el mismo formato
- El summary se actualiza conforme avanza el equipo
- Si no está documentado, no cuenta como progreso

---

## Objetivo

- Tener trazabilidad individual y colectiva
- Identificar avances reales
- Detectar bloqueos a tiempo
- Coordinar mejor el trabajo en equipo
